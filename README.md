# 🏆 Fantasy CS2

Веб-платформа для прогнозов на матчи CS2. Игроки угадывают победителя, kills игроков и тотал. За удачные прогнозы — очки, ELO и реальные призовые.

## 📌 Текущий статус
- **Версия:** v12.3
- **Режим:** прототип на localStorage (без сервера)
- **Фронт:** готов, задеплоен на Netlify, работает под VPN
- **Бэкенд:** не подключён (только тестовый `/api/health` на Node.js)
- **Следующий шаг:** Этап 2 — PostgreSQL schema

## 🛠 Стек
- **Frontend:** чистый HTML/CSS/JS (без фреймворков)
- **Backend (план):** Node.js + Express + PostgreSQL
- **Хранение сейчас:** localStorage браузера
- **Хостинг сейчас:** Netlify (фронт)
- **Хостинг (план):** Railway (бэк + БД) + РФ-хостинг для фронта (или Cloudflare)

## 🎮 Как работает (для игрока)
1. Регистрация (с капчей и TG-верификацией — пока демо)
2. Прогнозы на 3 рынка: победитель, kills игрока, тотал
3. Очки → магазин (бустеры, страховки, кейсы, косметика, значки)
4. ELO → ранги с наградами
5. Лиги (ежедневно/недельно/месячно) → реальные призовые
6. Выводы: СБП/карта/ЮMoney

| 💎 Средний | 120 🟡 | Очки 50-180, бустер +20/30% ×1-2, страховка ×2-3, малый кейс | **1/200** |

Перед открытием показывается **превью со списком возможных призов** (без шансов, только редкости).

## 🎨 Значки (v12.3)
Купленные значки можно **включать/выключать** в кастомизации. Показываются рядом с ником **в чате и профиле** только если активны:
- ⭐ VIP-значок (200 🟡)
- 👑 Корона (300 🟡)
- 🎯 Значок Охотника (350 🟡)
- ♛ Значок Короля (800 🟡)

## 🔐 Особенности
- **Fingerprint** — защита от мультиаккаунтов
- **Капча** — при регистрации
- **Вход/регистрация по Enter** — во всех полях
- **Лимиты вывода** — 10₽ / 200₽ / 500₽ (3 уровня)
- **Штрафы** — за неверный прогноз -150 очков
- **Бонус за задержку выплаты** — +5₽/час (макс 100₽)
